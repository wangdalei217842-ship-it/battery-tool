# 换成域名 + HTTPS 访问

> **状态：2026-10-23 09:43 已切换完成** ✅
> 现在正式地址是 **https://battery.bageedu.cn**（证书 Let's Encrypt，到期 2027-01-21，自动续期）。
> 程序已改为只监听 `127.0.0.1:8787`，`http://111.231.29.88:8787` 已经连不上了。
> 剩一件手动的事：到腾讯云防火墙把 **8787 的入站规则删掉**（现在它已经没用了）。

> 结论先说：他们说的「用域名」其实是**换成 HTTPS**。
> 只把地址从 `http://111.231.29.88:8787` 换成 `http://battery.xxx.cn:8787` **一点都不会更安全** —— 密码还是明文在网上跑。
> 真正的分界线只有两条：**有没有证书**、**8787 还对不对公网开放**。

## 二、动手四步

### 步骤 1：加解析（2 分钟）

`bageedu.cn` 的 DNS 托管在 **DNSPod**（NS 是 `cockroach.dnspod.net` / `eli.dnspod.net`），所以要去 DNSPod 那边加，不是腾讯云的「域名注册」页。

三个入口，哪个能进用哪个：

| 入口 | 地址 | 进去之后 |
|---|---|---|
| DNSPod 独立站（最直接） | https://console.dnspod.cn/dns/bageedu.cn/record | 直接就是这个域名的记录列表 |
| DNSPod 首页 | https://console.dnspod.cn/dns/list | 我的域名 → 点 `bageedu.cn` → 记录管理 |
| 腾讯云控制台 | https://console.cloud.tencent.com/dnspod/domain | 云解析 DNS → 我的域名 → 点域名 → 「解析记录」→ 添加记录 |

> 如果你现在看到的是腾讯云「域名注册 → 我的域名」那种卡片页，它只管域名本身；那页右边的「解析」按钮点一下会跳到 DNSPod。

添加记录时这样填：

| 字段 | 填什么 |
|---|---|
| 主机记录 | `battery` （只填前缀，不要写完整域名，也不要带点） |
| 记录类型 | `A` |
| 线路类型 | `默认` |
| 记录值 | `111.231.29.88` |
| TTL | `600` |

保存即可。只加这一条，**别动 `@` 和 `www`**（`www` 现在是正常的）。等 1～10 分钟，本机验证：

```bash
nslookup battery.bageedu.cn 223.5.5.5     # 要返回 111.231.29.88
```

> 实在找不到入口：DNSPod 支持 API。给我一个「DNSPod Token（ID + Token）」，我直接用 `Record.Create` 把这条例记录写进去。

### 步骤 2：安全组放行 443（1 分钟）

腾讯云 → 轻量应用服务器 → 防火墙 → 添加规则：`TCP 443`，来源 `0.0.0.0/0`。

### 步骤 3：一条命令签证书 + 配 Nginx（2 分钟）

```bash
ssh root@111.231.29.88
cd /opt/battery-tracker
sudo bash deploy/enable_domain.sh battery.bageedu.cn 你的邮箱
```

脚本做的事（顺序即执行顺序）：

1. 检查 `battery.bageedu.cn` 是否已指向本机，不指就停下
2. 先立一个只服务 `/.well-known/acme-challenge/` 的 80 站点（证书验证用）
3. `certbot` 走 **HTTP-01 webroot** 签证书 → 装到 `/etc/letsencrypt/live/battery.bageedu.cn/`
4. 换成正式配置：80 全部 301 跳 HTTPS；443 反代到 `127.0.0.1:8787`，带 HSTS、`X-Content-Type-Options`、登录限速
5. 给 systemd 加 drop-in：`BT_HOST=127.0.0.1`、`BT_SECURE=1`（Cookie 带 Secure 标记），重启服务
6. 自检：后端 200？外网 https 200？

> **如果以后 80 真的被备案拦了**，换成 DNS-01（不需要 80 端口）：
> ```bash
> sudo bash deploy/enable_domain.sh battery.bageedu.cn 你的邮箱 DNSPod_ID DNSPod_Token
> ```
> Token 在「DNSPod 控制台 → 用户中心 → API 密钥」创建。

### 步骤 4：把 8787 从公网关掉（关键，别省）

腾讯云防火墙 → **删除 8787 的入站规则**。

做完这一步，`http://111.231.29.88:8787` 彻底连不上，只剩 `https://battery.bageedu.cn`。
程序本身只听 `127.0.0.1`，即使有人扫到 8787 也连不上。

### 步骤 5：手机换地址

`https://battery.bageedu.cn` → 登录 → 分享/菜单 → 「添加到主屏幕」。
**上了 HTTPS 之后，「安装应用」按钮才会出现**（浏览器要求安全上下文），装上就是独立窗口、没有地址栏。

## 三、验收（四条命令）

> 别用 `curl -I`（HEAD）：后端只实现了 GET，HEAD 会被回 501，容易误判成挂了。用 `-o /dev/null -w` 看状态码。

```bash
# 1. 80 自动跳 443
curl -s -o /dev/null -w "%{http_code} -> %{redirect_url}\n" http://battery.bageedu.cn/
# 期望：301 -> https://battery.bageedu.cn/

# 2. 首页正常
curl -s -o /dev/null -w "%{http_code}\n" https://battery.bageedu.cn/
# 期望：200

# 3. 证书有效（加了 --cacert 时，证书链有问题会直接失败）
curl -s -o /dev/null -w "%{http_code}\n" \
  --cacert /etc/ssl/certs/ca-certificates.crt https://battery.bageedu.cn/
# 期望：200

# 4. 老地址已失效
curl -s -o /dev/null -w "%{http_code}\n" -m 6 http://111.231.29.88:8787/
# 期望：000（Connection refused）
```

浏览器里再确认：地址栏小锁、`F12 → Application → Service Workers` 注册成功。

## 四、出问题了

| 现象 | 原因 | 处理 |
|---|---|---|
| 证书签发失败 | 解析没生效 / 443 或 80 没放行 | `nslookup` 确认 IP；安全组补 443、80 |
| `curl https://域名` 超时 | 443 没放行 | 控制台加 TCP 443 规则 |
| 502 Bad Gateway | 后端没起来 | `systemctl status battery-tracker`、`journalctl -u battery-tracker -n 50` |
| 登录后一直跳回登录页 | 开了 `BT_SECURE` 但你在用 `http://` | 必须用 `https://` 打开 |
| 手机提示证书不受信任 | 旧书签还指着 IP | 手动输一次新地址再收藏 |

回滚到 IP 访问：

```bash
rm /etc/systemd/system/battery-tracker.service.d/domain.conf
systemctl daemon-reload && systemctl restart battery-tracker
# 再把安全组的 8787 入站规则加回来
```

## 五、为什么这样就安全了（可以拿去回他们）

| 攻击面 | 改造前 | 改造后 |
|---|---|---|
| 密码 / 数据 | HTTP 明文，链路上抓包即得 | TLS 1.2/1.3 加密 |
| 暴露面 | 8787 对全网开放 | 只开 443；8787 只听本机 |
| 暴力破解 | 无限制 | `/api/login` 限速 12 次/分钟/IP，超出 429 |
| 中间人 / DNS 劫持 | 无防护 | 证书校验 + HSTS（半年内只走 HTTPS） |
| 身份可信 | IP 说变就变 | 证书绑定域名，浏览器自动校验 |

跟域名无关、但同样该做的：

- 改掉 `admin` 的随机初始密码；别多人共用一个账号
- 每个人单独开账号（右上角 → 用户管理），数据本来就物理隔离
- 备份不要只留在服务器：定期把 `/var/backups/battery-tracker/` 拉一份回本地
